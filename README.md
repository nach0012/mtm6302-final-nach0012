# MyStyle – Personal Digital Wardrobe

**Developer:** Saida Nachit
**Course:** MTM6302 – Final Project

MyStyle helps students and young adults organize their clothes: add tops, bottoms and shoes, filter them by category, mark favourites, and delete items they no longer have.
